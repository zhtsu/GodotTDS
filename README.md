# Godot TDS

Godot plugin for supporting TapTap Developer Services

在 Godot 中使用 TapTap 开发者服务

# Environment

- OpenJDK 17.0.11
- TapSDK Android 4.9.2
- Dirichlet Ad SDK 4.2.0.1
- Godot 4.5.1

# Feature

### TapSDK

- [x] 登录（已完成）
- [x] 合规认证（已完成）
- [x] 内嵌动态（已完成）
- [x] 成就系统（已完成）
- [x] 礼包系统（已完成）
- [x] 排行榜（已完成）
  - 获取玩家周围排名数据的接口目前存在问题，无法使用
- [x] 云存档（已完成）
  - 目前在测试应用中获取云存档封面时存在明显卡顿
- [ ] 深度链接（开发中）
